# Creating vault entries

Use `⌘N` (or `Ctrl+N`) for a Markdown note and `⌘⇧N` (or `Ctrl+Shift+N`) for a folder. Right-click the explorer background for vault-root entries, a folder for entries inside it, or a note for entries beside it. Creation is confirmed in an accessible name dialog; notes receive the `.md` extension from the vault API. Existing destinations are reported in the dialog and are never overwritten. Successful notes open in the current tab (replacing an empty tab); successful creation refreshes the explorer only when the originating vault is still active. The dialog captures the originating vault ID so a later vault switch cannot redirect a write. Right-click a note or folder and choose **Move … to Trash** to request a confirmed move to the system Trash; entries are never permanently deleted.
