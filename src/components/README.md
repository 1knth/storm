# Vault groups

Choose **Group** in the Vaults pane and then select **Create from folder…** to make a group from a parent folder. The selected folder is used only as the group's suggested name; each immediate child folder is registered as a vault in that group. The selected parent itself is not registered, and files are not modified. Confirm the group name to complete the import; canceling the folder picker makes no registry changes. Empty folders cannot create groups. Existing vault entries are retained and assigned to the new group. Group headers show a small colored dot instead of a folder-tree icon. Right-click a group header or open its **⋯** actions menu and choose **Change color** to use the same palette as tab groups. Vault-group colors persist in the registry settings.
