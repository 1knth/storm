# Vault groups

Choose **Group** in the Vaults pane and then select **Create from folder…** to make a group from a parent folder. Each immediate child folder is registered as a vault in that group; if there are no child folders, the selected folder itself is registered as the vault. Files are not modified. Confirm the group name to complete the import; canceling the folder picker makes no registry changes. Existing vault entries are retained and assigned to the new group. Group headers show a small colored dot instead of a folder-tree icon. Right-click a group header or open its **⋯** actions menu and choose **Change color** to use the same palette as tab groups. Vault-group colors persist in the registry settings.
